# AI Claims Privacy & Governance Pack

**Independent simulation.** This project uses a fictional insurer and contains no real personal data. It is a learning exercise and not legal advice.

## Purpose
A privacy and governance pack for a fictional insurer's AI claims pre-assessment tool. It covers GDPR record-keeping, data flows, a Data Protection Impact Assessment and AI governance, the kind of work a junior GRC or privacy analyst supports.
