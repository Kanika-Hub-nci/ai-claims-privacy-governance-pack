# AI Claims Privacy & Governance Pack

**Independent simulation.** This project uses a fictional insurer and contains no real personal data. It is a learning exercise and not legal advice.

## Purpose
A privacy and governance pack for a fictional insurer's AI claims pre-assessment tool, covering GDPR record-keeping, data flows, a Data Protection Impact Assessment and AI governance.

## Contents
1. Use case
2. Data inventory
3. Data flow map
4. Record of Processing Activities (GDPR Article 30)
5. Data Protection Impact Assessment (GDPR Article 35)
6. AI governance note
7. Executive summary
